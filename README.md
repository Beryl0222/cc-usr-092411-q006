# 数字草书限量履约

本仓库保存该服务的领域资料、事件约定与统一履约链实现，供业务团队在统一语义上继续建设。

## 已有内容

- `contracts/domain.schema.json`：领域事件的基础字段、聚合类型和事件名称。
- `data/sample.json`：可用于联调的中文样例记录。
- `src/validator.py`：基础事件信封校验。
- `src/fulfillment/`：统一履约链实现（领域模型、事件存储、应用服务）。
- `tests/`：验证样例、基础约定与履约链行为保持一致。

## 统一履约链

```
版次登记（总量 + 保留范围）
  → 序号预占（可注入时钟过期，到期自动释放）
  → 付款确认（只锁定购买资格，支付回执幂等）
  → 实名复核（不通过则释放序号）
  → 链上登记（outbox 持久化，回执幂等，确认数字归属）
  → 实体发运（按同一归属生成任务；出库前地址变更须追加审批）
```

异常路径：

- **支付撤销**：登记完成前释放序号；已登记的数字归属不可回滚，只能进入补救案件。
- **链上失败**：终态失败释放序号重新可售；可重试失败留在 outbox 等待补登记。
- **物流退回**：数字归属不回滚，订单转入补救案件。
- **内容变化**：同一支付/登记回执内容前后不一致时，相关序号立案隔离调查。

## 关键设计

- **事件溯源**：`event_store` 只追加不改写；`serial_slots` 是由事件维护的序号唯一占用投影，
  重启后可整体重建。业务更正只产生后继事件。
- **并发安全**：同一序号的并发预占在数据库唯一约束上分胜负，只有一个赢家；
  单连接 + 事务锁保证读写不交错。
- **幂等**：支付回执、登记回执、退件回执完全重放返回原结果；预占支持命令幂等键。
- **可注入时钟**：`Clock` 抽象贯穿预占过期与恢复扫描，测试用 `FixedClock` 精确控制临界时刻。
- **重启恢复**：`recover()` 继续过期释放、补登记（registration_outbox）与退件处理（return_inbox）。
- **溯源查询**：`trace_serial(edition_id, serial)` 从任一序号还原预占、付款、登记、发运与补救依据。

## 本地检查

```bash
python3 -m unittest discover -s tests
```

## 测试与构建

测试命令：

```bash
python3 -m unittest discover -s tests
```

编译或构建命令：

```bash
python3 -m compileall -q src tests
```

上述命令用于本地核对服务代码，不需要另行启动外部基础设施。

## 领域边界

事件一旦被接收，其标识、发生时间和版本不应被原地改写；业务更正应产生后继记录。涉及个人、机构或商业敏感信息时，调用方只读取完成职责所必需的字段。
