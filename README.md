# 数字草书限量履约

本仓库实现数字草书限量序号的统一履约链：版次登记、序号预占、付款、实名复核、链上登记、实体装裱发运与补救案件，并保存领域事件约定供联调。

## 已有内容

- `contracts/domain.schema.json`：领域事件的基础字段、聚合类型和事件名称。
- `data/sample.json`：可用于联调的中文样例记录。
- `src/events.py`：事件类型与聚合类型常量，与契约枚举保持一致。
- `src/validator.py`：校验基础事件信封（必填字段、版本、类型枚举）。
- `src/clock.py`：可注入时钟（系统时钟 / 测试手动时钟）。
- `src/store.py`：追加式 JSONL 事件日志，启动时全量回放。
- `src/service.py`：统一履约链服务（命令、释放、幂等、恢复、查询）。
- `tests/`：覆盖主链路、临界过期、部分履约、重复回执、并发与重启恢复。

## 履约链

1. **版次登记**：`register_edition` 登记总量、保留范围与实体装裱额度；保留序号不参与发售。
2. **序号预占**：`hold_serial` 预占序号，`expires_at = 时钟 + 预占时长`；过期以可注入时钟判定，`expires_at <= now` 即过期（含临界时刻），由 `sweep_expired_holds` 释放。
3. **付款**：`confirm_payment` 只锁定购买资格（序号转为已售，尚未归属）；实体装裱在此时占用额度。
4. **实名复核 + 链上登记**：两者都通过后才由 `OWNERSHIP_CONFIRMED` 确认数字归属；实体装裱按同一归属生成发运任务。
5. **发运**：地址变更必须在出库前申请并审批通过；有待审批变更时禁止出库；出库后变更不予受理。
6. **释放**：支付撤销、链上失败、物流退回分别释放尚未完成的资源（序号、实体额度）；已登记的数字归属不可回滚，只能进入补救案件（`REMEDIATION_OPENED` → `ORDER_REMEDIED`）。

## 幂等与并发

- 同一支付或登记回执完全重放返回原结果（按回执内容指纹判定），不产生新事件。
- 回执标识相同但内容变化的，写入 `RECEIPT_QUARANTINED` 隔离调查，不改变既有状态。
- 序号分配在锁内完成，并发购买不会获得同一序号。

## 重启恢复

状态全部由事件日志重建。重启后调用 `recover()` 继续三类未完成工作：过期预占释放、待登记订单补登记（重新提交链上登记）、退回发运件处理（实体回补 + 补救案件）。

## 查询

`trace_serial(edition_id, serial_no)` 从任一序号还原预占、付款、登记、发运与补救依据（当前状态 + 事件证据）；`serial_status` 给出序号当前状态（RESERVED / AVAILABLE / HELD / SOLD / OWNED）。

## 领域边界

事件一旦被接收，其标识、发生时间和版本不应被原地改写；业务更正应产生后继记录。涉及个人、机构或商业敏感信息时，调用方只读取完成职责所必需的字段。

```bash
python3 -m compileall -q src tests
```

上述命令用于本地核对服务代码，不需要另行启动外部基础设施。
